# UI_aoharu 画像素材

イラストは下記のファイル名でこのフォルダに置くと自動で表示されます（未配置の間は何も表示されません）。
背景透過の PNG を推奨します。

| ファイル名 | 表示場所 | 推奨サイズ |
| --- | --- | --- |
| `students_running.png` | ログイン・新規登録画面の右下（走る3人） | 横 720px 前後 |
| `students_desk.png` | 生徒用画面の右下（机で話す3人） | 横 600px 前後 |
| `logo-scissors.svg` | 左上のロゴ（仮の SVG。差し替え可、PNG にする場合は CSS・テンプレートのパスも変更） | 正方形 |
